How to read this
Vol (1d / ann)GARCH(1,1) forecast of tomorrow's volatility — how much movement to expect, daily and annualized. σ²(t) = ω + α·r²(t−1) + β·σ²(t−1)  ·  ann = 1d × √252
OU z-scoreOrnstein–Uhlenbeck fit — how many standard deviations the price sits from its own fitted 1-year mean. 0 means "at its normal level". ln P(t) = c + φ·ln P(t−1) + ε  ·  z = (ln P − μ) / σε,  μ = c / (1−φ)
Half-lifefrom the same fit — how many days a stretch like this has historically taken to decay halfway back. t½ = ln 0.5 / ln φ
Mom 5dplain 5-day percent change — which way it's leaning right now. P(t) / P(t−5) − 1
